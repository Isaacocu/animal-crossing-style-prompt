# 动物森友会风格图片提示词

用这个技能写稳定、简洁、可直接交给生图模型的动物森友会风格图片提示词。

## 自带依赖

写提示词前先读 `references/acnh-visual-style.md`，拿完整视觉规范、角色规则、UI 规则、季节系统和元素池。

这个技能是独立提示词技能，随 skill 一起发布的 `references/` 已包含所需视觉规范。

## 提示词模板

默认使用这个模板。替换方括号里的内容，并保持行序。

```text
动物森友会原版游戏实况截图复刻
画风：任天堂 Switch 集合啦！动物森友会实机游戏截图风格；不要写实摄影、不要电影 CG、不要赛璐珞动画、不要像素风、不要水彩手绘
玩家角色 + 同行动物邻居：[岛民默认造型，搭配 1-2 只动物邻居名称]

岛屿区域：[地点或主题，例如「北京·颐和园」/「自家后花园」/「海边咖啡店」]
画面要素：[3-5 个可识别关键词，只列名词或短词组]
生活时刻：[一句话叙事，写角色正在做什么；使用工具时写「正在使用工具」，休闲时写「休闲状态」]

动森元素：[3-7 个关键词，只列名称不展开外观]
季节与时段：[春/夏/秋/冬 + 早晨/白天/傍晚/夜晚]
岛名 UI 文字：右下角小字「[岛屿名称]岛」；按原版登岛画面风格呈现，白色无衬线小字、半透明、不加边框底纹
UI 界面：按 ACNH 原版游戏实况自然出现，不堆满
文字：所有可读 UI 使用中文，按键提示只用中文动词，如「捡起」「对话」「钓鱼」「制作」
```

## 填写规则

- 提示词控制在 10-13 行左右。不要加前景/中景/远景分层、镜头焦段、材质描述或长篇光线描述。
- `画风` 行不要再加 `Q版建模、低多边形、柔焦散景、tilt-shift移轴、卡通渲染管线` 等风格串。
- 动物邻居只写名字（如 `西施惠、K.K.、傅珂、茶茶丸`），不展开毛色、衣服、表情等外观细节——模型从名字就能还原。
- 玩家角色默认使用 ACNH 岛民造型（圆头短身 Q版比例）。只有用户明确要求特定服装（如「穿圣诞毛衣」「穿浴衣」）时才补充一句服装描述。
- 尊重用户的角色边界。用户说不要玩家角色，就去掉玩家角色只保留动物邻居；用户只要特定邻居，就只写那个邻居。
- 真实地点的建筑、地形、植被要保留核心辨识特征，但转译为动森建筑语言（圆润、矮胖、糖果色、小尺寸）。现代基础设施替换为动森等价物（停车场→小广场、电线杆→路灯、广告牌→告示牌）。
- `岛屿区域` 是风格锚点字段名；即使用于真实地点，也不代表 UI 文字要写游戏内岛名。
- `画面要素` 承担主体辨识度，使用地标名词、家具特征、植物种类、活动道具等短关键词。
- `动森元素` 只写紧凑列表，例如 `Nook商店、博物馆、摇钱树、化石挖掘点、气球礼物、篝火`。不要展开颜色、材质或位置。
- `季节与时段` 决定整体氛围。不需要在 prompt 里展开光影——交给模型按季节+时段自处理。
- 岛名规则：真实地点用真实地名做岛名（如「颐和园岛」「浅草岛」）；虚构场景用主题命名（如「咖啡岛」「星空岛」）。不要用游戏内默认岛名。
- 如场景适合出现特定 NPC（海滩→吕游、夜晚→傅珂、周六→K.K.），可在动森元素里自然加入，但不要每张图都塞满 NPC。
- 如场景没有真实上级区域，岛名用简短中文主题归属，例如 `咖啡岛` 或 `温泉岛`；不要写宣传语。

## 输出模式

只返回最终提示词代码块，不要附带任何其他说明。
