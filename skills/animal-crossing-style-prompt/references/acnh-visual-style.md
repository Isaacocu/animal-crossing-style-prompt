# 动物森友会游戏实况截图视觉风格

本文档是 `animal-crossing-style-prompt` 的内置视觉规范。写提示词前按本文档确定画风、角色、UI、季节系统和元素池。

## 1. 画面总目标

按「原版动物森友会游戏实况截图复刻」方向写 prompt。目标是 ACNH（集合啦！动物森友会）Switch 实机画面，不是奇幻插画、不是写实摄影、不是像素风。

- **画风锚定（正反双向）**：prompt 必须有单独的 `画风` 字段，集中写实机截图风格和反向禁词。

  ```text
  动物森友会原版游戏实况截图复刻
  画风：任天堂 Switch 集合啦！动物森友会实机游戏截图风格；不要写实摄影、不要电影 CG、不要赛璐珞动画、不要像素风、不要水彩手绘
  ```

  历史经验：只写「动森风格」容易滑向 Q 版插画或卡通渲染；加上「实机游戏截图」+ 反向禁词后稳定性显著提升。

- **相机**：俯视 45° 等距视角（ACNH 默认镜头），角色在画面中部偏下。不要写死俯角度数或镜头焦段。`16:9 横图` 由出图工具的尺寸参数指定，prompt 里**不需要再写**画面比例。
- **色调**：柔和粉彩色系，饱和度中等偏高，无强对比阴影。不要在 prompt 里写色号或 HSL 数值——交给模型按「ACNH 实机」心锚自处理。
- **建筑比例**：所有建筑都是「小人国」尺度——矮胖圆润、一层或两层高、门窗比人物大。真实建筑要按此比例缩放转译。

## 2. 角色规则

### 玩家角色
- ACNH 岛民默认造型：圆头、短身、大眼、无鼻、2-3 头身比例
- prompt 里只写「岛民默认造型」即可，不展开五官、肤色、发型——模型从心锚自处理
- 用户要求特定服装时才补充一句（如「穿红色雨衣」）

### 动物邻居
- 只写名字，不写外观。例：写「茶茶丸」而非「一只蓝色眼睛的公牛，穿着运动衫」
- 常见高人气邻居供选用：茶茶丸、杰克、阿判、朱迪、仰望、柠檬娜、小润、艳后、1号、三明治

### NPC 场景绑定

| NPC | 适合出现的场景 |
|---|---|
| 西施惠 | 广场、服务处前、岛屿日常 |
| 狸克/豆狸粒狸 | Nook 商店、购物场景 |
| 傅珂 | 夜晚、星空、流星雨 |
| K.K. | 周六晚、广场演唱、音乐主题 |
| 吕游/吕游海盗 | 海滩、漂流物、异国主题 |
| 骆岚 | 来访日、地毯/壁纸/地板主题 |
| 龙克斯 | 虫类主题、夏季 |
| 俞司廷 | 鱼类主题、钓鱼大赛 |

不要每张图都塞满 NPC，按场景自然出现 0-2 个。

## 3. UI 与界面规则

UI 是真实游戏截图里自然出现的元素，不是堆满的信息图。

### 基础 UI（按画面叙事自然出现 1-3 种，不堆满）
- 口袋（背包）图标
- 铃钱计数
- 时间/日期
- 迷你地图
- 互动按键提示
- NPC 对话气泡（圆角矩形、奶白色底）
- 表情反应气泡
- 岛名/区域名显示

### UI 极简原则
不要在 prompt 里写 UI 的形状、位置、颜色、像素尺寸。只写方向性指令：
- ✅ `UI 界面：按 ACNH 原版游戏实况自然出现，不堆满`
- ✅ 对话内容要写：`对话气泡「西施惠：今天天气真好呢！」`
- ❌ 不要写：`左上角显示铃钱 99999、右下角圆形 A 按钮`

### 中文化规则
所有可读文字使用中文。允许的按键动词：
```
捡起、种植、钓鱼、捕虫、挖掘、摇树、对话、坐下、拍照、装饰、制作、许愿
```
禁止出现英文 UI 词（Pick up、Plant、Fish 等）。

## 4. 岛名 UI 样式

场景图默认在右下角显示岛名，按 ACNH 原版登岛画面风格：
- 白色无衬线小字，半透明
- 格式：「[岛名]岛」
- 不加边框、底纹、装饰
- 真实地点用真实地名做岛名（「颐和园岛」）；虚构场景用主题命名（「星空岛」）

|---|---|
| 春 | 樱花飘落、嫩绿草地、蝴蝶、复活节彩蛋 |
| 夏 | 向日葵、椰子树、烟花、萤火虫、潜水服 |
| 秋 | 红叶、蘑菇、橡果松果、落叶堆、万圣节南瓜 |
| 冬 | 积雪、雪人、极光、圣诞装饰、冰晶地面 |

| 时段 | 光线特征 |
|---|---|
| 早晨 | 柔和暖黄光、薄雾、露珠 |

prompt 里只写「季节与时段：夏·傍晚」，具体视觉效果交给模型自处理。

## 6. 动森元素池

### 建筑设施
Nook 商店、服装店、博物馆、服务处、露营地、玩家小屋、桥梁、斜坡、灯塔、钟楼

### 自然景观
果树（苹果/橘子/梨/桃/樱桃/椰子）、花圃、河流、瀑布、池塘、悬崖、沙滩、岩石

### 家具与装饰
路灯、长椅、喷泉、拱门、摊位、邮筒、告示牌、篱笆、石板路、木栈道、秋千、露天咖啡座

### 工具与道具
鱼竿、捕虫网、斧头、铲子、弹弓、梯子、撑杆、浇水壶、照相机、DIY 工作台

### 收藏品与生物
化石挖掘点（星形裂缝）、摇钱树、气球礼物（飘在天上的彩色气球+礼物盒）、蝴蝶、萤火虫、海洋生物

### 活动与事件
钓鱼大赛、捕虫大赛、烟花大会、K.K. 演唱会、流星许愿、化石发掘

## 7. 真实地点转译规则

| 真实元素 | 动森转译 |
|---|---|
| 高层建筑 | 2层矮胖圆润小楼 |
| 停车场/公路 | 石板小广场/土路 |
| 电线杆/信号灯 | 木质路灯/风车 |
| 广告牌/霓虹灯 | 木质告示牌/纸灯笼 |
| 现代栏杆/铁丝网 | 木篱笆/石墙 |
| 游客/路人 | 动物邻居 NPC |
| 汽车/摩托 | 无（省略或替换为小推车） |
| 钢筋混凝土 | 圆润石砖/木质结构 |

核心原则：保留真实地点的**地形轮廓和文化符号**（如故宫的红墙黄瓦、富士山的锥形轮廓），但把材质、比例、细节全部转译为动森的圆润矮胖糖果色语言。

## 8. 必须避免清单

- 不要写实摄影、电影 CG、赛璐珞动画、像素风、水彩手绘
- 不要真实人类比例（写实人体、真实面孔、正常头身比）
- 不要暗黑、恐怖、血腥元素（动森是全年龄向）
- 不要现代工业设施（工厂烟囱、高压电塔、建筑工地）
- 不要 UI 堆满屏幕——像一张正在玩的游戏截图
- 不要镜头焦段、景深参数、色号数值等摄影术语
- 不要把家具和元素排成对称清单式摆拍——要像游戏中自然摆放
